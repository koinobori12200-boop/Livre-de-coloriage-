# 📚 Mon Livre Magique

54 jeux éducatifs pour enfants — PWA installable, fonctionne hors-ligne.

## 🚀 Déploiement sur GitHub Pages (5 minutes)

### 1. Créer le dépôt
- Va sur **github.com** → clique **+** → **New repository**
- Nom : `mon-livre-magique`
- Visibilité : **Public** (obligatoire pour Pages gratuit)
- **Ne pas** cocher "Add README" → clique **Create repository**

### 2. Uploader les fichiers
Clique **uploading an existing file** ou **Add file → Upload files**, puis glisse :
- `index.html`
- `manifest.json`
- `sw.js`
- `icon.svg`
- `README.md`

Clique **Commit changes**.

### 3. Activer GitHub Pages
- **Settings** (onglet du dépôt)
- Menu de gauche → **Pages**
- **Source** : `Deploy from a branch`
- **Branch** : `main` + `/ (root)`
- Clique **Save**
- Attends 1-2 minutes

### 4. Accéder à l'app
Ton lien : `https://TON-PSEUDO.github.io/mon-livre-magique/`

### 5. Installer sur mobile
Sur Android (Chrome) : ouvre le lien → clique **📲 Installer** dans l'app, ou menu ⋮ → « Installer l'application ».
